R1 Extension v1.1

Pages:
- Visit Data: save object data. F5 runs Visit Data ONLY.
- ConMed: paste pipe-delimited ConMed records and click Enter ConMed.
- Medical History: paste pipe-delimited history records and click Populate Medical History.

Code is split into separate files: visit-data.js, conmed.js, medical-history.js, router.js, and separate popup scripts/pages.

Install: Chrome/Edge > Extensions > Developer mode > Load unpacked > select R1_extension.

Important: test in a non-production/test record before use. The scripts populate fields but do not intentionally perform final study-form save/submit actions.
