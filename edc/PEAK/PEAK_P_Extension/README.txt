PEAK P Chrome/Edge Extension

INSTALL
1. Unzip PEAK_P_Extension.zip.
2. Open chrome://extensions (or edge://extensions).
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select the PEAK_P_Extension folder.

USE
1. Click the light-blue P extension icon.
2. Paste your PEAK data object and click Save data.
3. Open the PEAK form page.
4. Press F2.

The extension uses the form-filling logic supplied in Pasted text.txt.
