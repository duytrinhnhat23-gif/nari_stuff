Clinical Data Extractor - Chrome/Edge Extension

Install locally:
1. Unzip this folder.
2. Open chrome://extensions (or edge://extensions).
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the clinical-data-extractor folder.
6. Open the clinical-study page, click the extension, choose Visit / ConMed / Medical History, and click Extract.

Notes:
- The extension only reads the currently active tab after you click an Extract button.
- Results are shown in the popup and copied to the clipboard.
- Medical History expects #pop-out-multi-record-modal to be present/open.
- ConMed expects table.record rows with ids beginning completed_record_row_.
